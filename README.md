# CAIM Discretization Algorithm — Reproduction

This repository contains the Python implementation and benchmark reproduction of the **CAIM (Class-Attribute Interdependence Maximization)** discretization algorithm by Kurgan & Cios (2004), evaluated on the UCI Iris Plants dataset using 10-fold cross-validation.
